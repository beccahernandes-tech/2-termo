📚 Disciplinas
🔹 LIMA — Linguagem de Marcação

Estudo de linguagens de marcação utilizadas no desenvolvimento web, com foco na estruturação e organização de páginas. Desenvolvimento de páginas utilizando HTML e CSS, trabalhando com elementos, formulários, tabelas, links, imagens e estilização.

🔹 BCD — Banco de Dados

Introdução aos conceitos de bancos de dados relacionais, abordando criação e organização de tabelas, relacionamentos entre dados e consultas. Utilização de SQL para inserir, alterar, excluir e consultar informações.

🔹 PBE1 — Programação Backend

Desenvolvimento da lógica de aplicações no lado do servidor (backend), trabalhando com programação, manipulação de dados, regras de negócio e integração com bancos de dados. Introdução ao desenvolvimento de aplicações utilizando APIs.

🔹 Backend

Aprofundamento no desenvolvimento de sistemas backend, trabalhando com servidores, APIs, banco de dados, autenticação e integração entre diferentes partes de uma aplicação. Foco na criação de aplicações funcionais, organizadas e eficientes.
