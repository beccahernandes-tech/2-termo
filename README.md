📚 2º Termo — Desenvolvimento de Sistemas

Repositório destinado ao armazenamento das atividades, exercícios e projetos desenvolvidos durante o 2º termo do curso de Desenvolvimento de Sistemas.

📖 Disciplinas
🌐 LIMA — Linguagem de Marcação

Nesta disciplina foram desenvolvidas atividades voltadas para a estruturação de páginas web, utilizando linguagens de marcação e estilização. O conteúdo foi organizado em atividades práticas realizadas ao longo das aulas, envolvendo a criação e organização de páginas e seus elementos.

Principais conteúdos:

HTML
Estrutura de páginas web
Elementos HTML
Formulários
Organização e estilização de páginas
Desenvolvimento de páginas web
🗄️ BCD — Banco de Dados

Estudo dos fundamentos de banco de dados, com atividades práticas realizadas durante as aulas. Os exercícios abordam a organização e manipulação de informações, trabalhando conceitos necessários para o desenvolvimento de aplicações que utilizam dados.

Principais conteúdos:

Conceitos de banco de dados
Estrutura e organização de dados
Tabelas e relacionamentos
Consultas e manipulação de dados
SQL
💻 PBE1 — Programação Backend

Disciplina focada na introdução à programação no lado do servidor, utilizando JavaScript e desenvolvendo exercícios práticos. O repositório contém atividades em .js, exercícios de aula e projetos, incluindo uma atividade relacionada a logística.

Principais conteúdos:

JavaScript
Lógica de programação
Programação backend
Funções
Manipulação de dados
Desenvolvimento de aplicações
Práticas com Node.js
⚙️ BACKEND

Aprofundamento dos conhecimentos em desenvolvimento backend, com projetos e exercícios utilizando JavaScript e Node.js. Entre os arquivos desenvolvidos estão aplicações relacionadas a balança, com separação entre a aplicação e suas funções.

Principais conteúdos:

Node.js
JavaScript
Funções e módulos
Desenvolvimento de aplicações backend
Organização de código
Manipulação de dados
Estruturação de projetos
